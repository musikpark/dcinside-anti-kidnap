# DCInside Anti-Kidnap

A Tampermonkey userscript that automatically enables these options when writing a DCInside post:

- **No Repost**
- **Request Exclusion from Realtime Best**

Supports regular, minor, and mini galleries. Options that are already enabled are left as they are.

## Installation

1. Install Tampermonkey.
2. Create a new userscript and paste the script.
3. Save it and open a DCInside post editor.

or 

Install Tampermonkey, then [click here to install the script](https://raw.githubusercontent.com/musikpark666/dcinside-auto-anti-kidnap/main/dcinside-auto-anti-kidnap.user.js).

> Realtime Best exclusion is a request and does not guarantee exclusion.
